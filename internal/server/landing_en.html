towstrap

A reverse-connect remote access system: the controlled machine joins via outbound connection — no public address or inbound ports needed. SSH for humans, MCP for AI agents.

反向连接远程访问系统：被控机以出站连接接入，无需公网地址与入站端口；SSH 面向人工接入，MCP 面向 AI 代理。

The script downloads a binary matching this server's version for your architecture from GitHub Releases and verifies its SHA256. A resident service is registered and started by default (a systemd unit on Linux, a com.towstrap.agent launchd item on macOS, a system service on Windows) — pass --no-service (-NoService in PowerShell) to only place the binaries. You can also fetch the script straight from GitHub: curl -fsSL https://raw.githubusercontent.com/towstrap/towstrap/main/scripts/install.sh | sh -s --{{SH_TOKEN_ARG}}{{VERARG}} (without --version it defaults to the official server and latest).

05

Self-host

data stays on your own machines
# Server install (GitHub raw): binary + server.yaml + systemd service (Linux + root)
curl -fsSL https://raw.githubusercontent.com/towstrap/towstrap/main/scripts/install-server.sh | sudo sh
# Then run the init wizard: public address / self-registration / first account
sudo towstrap-server init
Binaries are downloaded from GitHub Releases and verified against SHA256SUMS. After install, run towstrap-server init to configure the public address, self-registration and the first account (re-runnable); the HTTP side is reverse-proxied through nginx on 443, the SSH port is exposed directly. Accounts live in a local SQLite database — no third-party dependencies.
