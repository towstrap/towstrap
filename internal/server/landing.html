towstrap

反向连接的远程访问：被控机不开端口、不要公网 IP，一条命令装好，SSH 和 AI 都能上。

Reverse-connect remote access — the controlled machine opens no inbound ports; SSH for humans, MCP for AI agents.

安装 agent（被控机上跑）

向管理员要到 agent token（tsa-…）后选一条：

# Linux / macOS —— 从这台服务器拉（地址已填好）
curl -fsSL {{BASE}}/install.sh | sh -s -- --token tsa-…{{VERARG}}

# Windows（PowerShell）
powershell -Command "& { $(irm {{BASE}}/install.ps1) } -Token tsa-…{{VERARG}}"

脚本按系统架构从 GitHub Releases 下载与服务器同版本的二进制、SHA256 校验后安装；加 --systemd 顺带装成服务。也可以从 GitHub 直接拉脚本：curl -fsSL https://raw.githubusercontent.com/towstrap/towstrap/main/scripts/install.sh | sh -s -- --token tsa-…{{VERARG}}（不加 --version 时默认指向官方服务器 + latest）。

连上去（你的电脑）

# 标准 OpenSSH 直连，不用装客户端
ssh -p {{SSHPORT}} 账号@{{HOST}}

# 可接力终端：detach 后进程照跑，换设备接回同一画面
ssh -t -p {{SSHPORT}} 账号@{{HOST}} 'mirror work'

镜像内 Ctrl-\ 脱离；本机装 towstrap 后还有 mirror ls / kill 等管理命令。

能力

反向连接，零入站——agent 主动连出 WebSocket，NAT/防火墙后面也能到
标准 SSH——密码 + TOTP + 公钥，限速防爆破，一个账号多台机器
MCP 给 AI 用——Claude Code / Cursor 直连跑命令、读写文件，审批保底
镜像终端——tmux 式常驻终端，不依赖 tmux，多端同屏接力
审计与通知——会话起止桌面提醒、wall 广播、全量审计日志
单二进制——server / agent / mcp 三个可执行文件，无外部依赖
