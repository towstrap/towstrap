towstrap

反向连接远程访问系统：被控机以出站连接接入，无需公网地址与入站端口；SSH 面向人工接入，MCP 面向 AI 代理。

A reverse-connect remote access system — the controlled machine requires no public address or inbound ports; SSH for interactive access, MCP for AI agents.

server {{VERSION}} ssh :{{SSHPORT}} host {{HOST}}

安装 agent

于被控机执行

# Linux / macOS —— 由本服务器下发（地址已写入）
curl -fsSL {{BASE}}/install.sh | sh -s --{{SH_TOKEN_ARG}}{{VERARG}}
# Windows（PowerShell）
powershell -Command "& { $(irm {{BASE}}/install.ps1) }{{PS_TOKEN_ARG}}{{VERARG}}"

脚本按系统架构从 GitHub Releases 下载与服务器同版本的二进制并校验 SHA256。默认注册并启动常驻服务（Linux 建 systemd 单元、macOS 建 launchd 项 com.towstrap.agent、Windows 建计划任务）——只放二进制不常驻就加 --no-service（PowerShell 用 -NoService）。亦可从 GitHub 直接获取脚本：curl -fsSL https://raw.githubusercontent.com/towstrap/towstrap/main/scripts/install.sh | sh -s --{{SH_TOKEN_ARG}}{{VERARG}}（未指定 --version 时默认官方服务器与 latest）。

02

接入

于客户端执行
# 标准 OpenSSH 协议，系统自带客户端即可接入
ssh -p {{SSHPORT}} 账号@{{HOST}}
# 持久终端：脱离后进程保持运行，可从其他设备恢复同一会话
ssh -t -p {{SSHPORT}} 账号@{{HOST}} 'mirror work'

会话内 Ctrl-\ 脱离；本机安装 towstrap 后可使用 mirror ls / kill 等管理命令。

03

MCP —— 给 AI 客户端接入

让 LLM 操作被控机
# 管理员在服务器上签发 MCP token（指定授权哪台/哪些机器）
towstrap-server mcp add my-laptop --machine alice
# 跑 AI 助手的机器上一键接入：装 towstrap-mcp 并把配置写进检测到的各家助手
curl -fsSL {{BASE}}/install-mcp.sh | sh -s -- --token tsm-…

接入写入检测到的助手配置：Claude Code / Codex / Grok Build / Cursor / Gemini / OpenCode / Copilot / Devin / Pi——原文件自动备份 .bak，--harness 可只写指定几家，同时把 towstrap skill 装进各助手（--no-skills 跳过）。Windows 机器从 GitHub Releases 下 towstrap-mcp-windows-amd64.exe，跑 towstrap-mcp connect mcp --url {{BASE}}/mcp --token tsm-… 效果相同。需要人工批准的操作落在本机待批：towstrap-mcp pending / approve。

05

能力

反向连接，零入站agent 经 WebSocket 主动出站，位于 NAT/防火墙内侧亦可接入，被控机无需开放端口
标准 SSH密码 + TOTP + 公钥认证，登录限速；单账号多机，以 alice+box@ 指名接入
MCP 接口Claude Code / Cursor 等客户端可执行命令、读写文件、管理终端，三级策略与人工审批
持久终端自实现的常驻终端（不依赖 tmux），Ctrl-\ 脱离后可从其他设备恢复同一会话
审计与感知会话起止桌面通知与广播，连接/执行/审批/凭据变更全程审计
单二进制server / agent / mcp 三个独立可执行文件，无外部依赖，可直接部署
06

自行部署

数据保存在自有机器
# 服务端安装（GitHub raw）：二进制 + server.yaml + systemd 服务（Linux+root）
curl -fsSL https://raw.githubusercontent.com/towstrap/towstrap/main/scripts/install-server.sh | sudo sh
# 随后执行初始化向导：对外地址 / 自助注册 / 首个账号
sudo towstrap-server init
二进制从 GitHub Releases 下载并校验 SHA256SUMS。安装后执行 towstrap-server init 配置对外地址、自助注册与首个账号（可重复执行）；HTTP 面由 nginx 443 反代对外，SSH 端口直接放行。账号库为本地 SQLite，无第三方依赖。
